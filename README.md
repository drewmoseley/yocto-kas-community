# yocto-kas-community

Kas configuration for community Yocto test builds (starting with **wrynose**), replacing the
`repo` + `yocto-manifest` workflow. Work in progress: design is being worked out with the
mattpocock engineering skills (`.claude/skills/`), starting with `/grill-with-docs`.

Checkouts and build output are not in this repo.
